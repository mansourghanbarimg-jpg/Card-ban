# کارت‌بان — گاوصندوق کارت‌های بانکی

یک وب‌اپ فارسی، راست‌چین و قابل نصب روی آیفون (PWA). داده‌ها در حافظه مرورگر همان دستگاه ذخیره می‌شوند و محتوای کارت‌ها با AES-GCM رمزگذاری می‌شود.

## انتشار روی GitHub Pages
1. یک Repository جدید در GitHub بساز.
2. فایل‌های این پوشه (`index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`) را در ریشه Repository آپلود کن.
3. از Settings → Pages، گزینه Deploy from a branch را انتخاب کن، Branch را روی `main` و Folder را روی `/ (root)` بگذار.
4. پس از فعال شدن Pages، سایت را در Safari آیفون باز کن.
5. از Share → Add to Home Screen آن را به صفحه اصلی اضافه کن. اولین بار یک رمز اصلی حداقل ۸ کاراکتری بساز.

## امکانات
- رمز ورود اصلی؛ رمزنگاری محلی با PBKDF2 + AES-GCM
- ثبت، ویرایش، حذف و جست‌وجوی کارت‌ها
- صفحه جزئیات مجزا با دکمه بازگشت به خانه
- کپی با نگه‌داشتن انگشت روی نوشته‌های کارت (حدود ۵۲۰ میلی‌ثانیه)
- کپی یک‌جای اطلاعات کارت
- ثبت CVV2 به‌صورت مخفی در داده رمزگذاری‌شده؛ نمایش فقط پس از وارد کردن دوباره رمز اصلی و پنهان‌شدن خودکار پس از ۱۵ ثانیه
- ثبت CVV2 به‌صورت مخفی در داده رمزگذاری‌شده؛ نمایش پس از ورود دوباره رمز اصلی و پنهان‌شدن خودکار پس از ۱۵ ثانیه
- تغییر رمز، قفل دستی، خروجی و بازیابی پشتیبان رمزگذاری‌شده
- ظاهر واکنش‌گرا و نصب‌پذیر؛ فایل‌های ثابت پس از اولین بازدید cache می‌شوند

## نکات مهم امنیتی
- این برنامه سرور یا همگام‌سازی ابری ندارد؛ داده‌ها فقط در storage مرورگر همان دستگاه می‌مانند.
- رمز را فراموش نکنی؛ بدون رمز اصلی، داده رمزگذاری‌شده قابل بازیابی نیست. فایل پشتیبان را جداگانه و امن نگه دار.
- پاک‌کردن داده‌های Safari، حذف وب‌سایت یا پاک‌سازی storage ممکن است اطلاعات محلی را حذف کند؛ مرتباً پشتیبان بگیر.
- ذخیره CVV2 ریسک امنیتی دارد؛ این نسخه آن را فقط در داده رمزگذاری‌شده محلی نگه می‌دارد و برای نمایش دوباره رمز اصلی می‌خواهد. CVV2 در نمای فهرست و کپی یک‌جای کارت‌ها نمایش داده نمی‌شود. از این قابلیت فقط روی گوشی شخصیِ قفل‌شده استفاده کن. رمز اول و رمز دوم بانکی را ذخیره نکن.
- رمزگذاری داده‌ها در مرورگر به HTTPS نیاز دارد؛ GitHub Pages این مورد را فراهم می‌کند.
- این برنامه برای استفاده شخصی طراحی شده و جایگزین کیف پول بانکی یا ابزار امنیتی تخصصی نیست.

## نکته فنی
نسخه فعلی از `localStorage` رمزگذاری‌شده استفاده می‌کند. فایل پشتیبان نیز ciphertext رمزگذاری‌شده است و برای بازیابی به رمز اصلی نیاز دارد.
