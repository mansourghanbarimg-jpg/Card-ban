# کارت‌بان نسخه ۳ — گاوصندوق کارت‌های بانکی

کارت‌بان یک وب‌اپ فارسی، راست‌چین و قابل نصب روی آیفون (PWA) است. این نسخه، پروژه نسخه دوم را ارتقا می‌دهد و ساختار ذخیره‌سازی و رمزگذاری قبلی را حفظ می‌کند؛ اطلاعات موجود در مرورگر با جایگزینی فایل‌های برنامه پاک نمی‌شوند.

## انتشار روی GitHub Pages

1. فایل‌های داخل پوشه `cardban` (یعنی `index.html`، `manifest.webmanifest`، `sw.js` و `icon.svg`) را در ریشه Repository آپلود یا جایگزین کن.
2. از مسیر Settings → Pages، گزینه Deploy from a branch را انتخاب کن؛ Branch را روی `main` و Folder را روی `/ (root)` بگذار.
3. پس از فعال‌شدن GitHub Pages، سایت را در Safari آیفون باز کن.
4. از Share → Add to Home Screen آن را به صفحه اصلی اضافه کن.
5. با همان رمز اصلی نسخه قبلی وارد شو. برای اطلاعات موجود نیازی به ساخت گاوصندوق تازه نیست.

## تغییرات نسخه ۳

- رفع اعتبارسنجی CVV2 برای ۳ یا ۴ رقم.
- پشتیبانی از ارقام فارسی، عربی و انگلیسی در CVV2 و شماره کارت؛ ارقام فارسی و عربی پیش از اعتبارسنجی به انگلیسی تبدیل می‌شوند.
- CVV2 همچنان در داده رمزگذاری‌شده ذخیره می‌شود؛ نمایش دوباره آن نیازمند ورود مجدد رمز اصلی است و پس از ۱۵ ثانیه خودکار مخفی می‌شود.
- CVV2 در کپی یک‌جای اطلاعات کارت قرار نمی‌گیرد.
- نمایش شماره کارت در جزئیات با جهت چپ‌به‌راست و گروه‌بندی چهارتایی صحیح.
- حفظ پنج رنگ قبلی و افزودن رنگ‌های قرمز، طوسی، آبی آسمانی، مشکی، صورتی، سرخابی، سفید، کرمی، سفید طلایی، سفید مشکی، مشکی طلایی و سفید آبی.
- نوار سفید تزئینی ظریف روی کارت‌ها، بدون پوشاندن نوشته‌ها یا اطلاعات.
- امکان تغییر رنگ کارت ثبت‌شده از صفحه جزئیات، بدون حذف یا تغییر سایر اطلاعات آن.
- به‌روزرسانی نسخه کش Service Worker به `cardban-static-v3` و دریافت تازه فایل HTML هنگام بازشدن برنامه.

## امکانات حفظ‌شده

- رمز اصلی ورود به برنامه.
- رمزگذاری محلی با PBKDF2 و AES-GCM.
- ثبت، ویرایش، حذف، جست‌وجو و مشاهده جزئیات کارت‌ها.
- کپی نوشته‌ها با نگه‌داشتن انگشت و کپی یک‌جای اطلاعات کارت.
- تغییر رمز اصلی و قفل دستی برنامه.
- خروجی و بازیابی پشتیبان رمزگذاری‌شده.
- ظاهر فارسی، راست‌چین و نصب‌پذیری PWA.

## سازگاری اطلاعات و پشتیبان

برای سازگاری، کلید ذخیره‌سازی قبلی (`cardban_v1_vault`)، قالب رکورد رمزگذاری‌شده، قالب داده کارت‌ها، تعداد تکرار PBKDF2 (۳۱۰٬۰۰۰) و الگوریتم AES-GCM تغییر نکرده‌اند. بنابراین:

- فایل‌های برنامه را می‌توان روی نسخه قبلی جایگزین کرد؛ داده‌های ذخیره‌شده در `localStorage` دست‌نخورده می‌مانند.
- نسخه سوم از همان گاوصندوق موجود با رمز اصلی قبلی استفاده می‌کند.
- فایل‌های پشتیبان نسخه دوم که با قالب پشتیبان همین پروژه ساخته شده‌اند، از مسیر «بازیابی پشتیبان» قابل بازیابی هستند.
- رنگ کارت‌های قبلی که مقدار رنگ آن‌ها در فهرست قدیمی وجود دارد حفظ می‌شود؛ رنگ‌های جدید فقط به‌عنوان انتخاب‌های اضافه در دسترس‌اند.

**مهم:** قبل از جایگزینی فایل‌ها، یک پشتیبان رمزگذاری‌شده از نسخه فعلی بگیر و آن را در جای امن نگه دار. فایل ZIP شامل فایل‌های برنامه است و داده‌های شخصی ذخیره‌شده در مرورگر را در خود ندارد.

## نکات امنیتی

- برنامه سرور یا همگام‌سازی ابری ندارد؛ داده‌ها فقط در حافظه مرورگر همان دستگاه ذخیره می‌شوند.
- رمز اصلی را فراموش نکن؛ بدون رمز درست، داده رمزگذاری‌شده قابل بازیابی نیست.
- پاک‌کردن داده‌های Safari، حذف وب‌سایت یا پاک‌سازی storage ممکن است اطلاعات محلی را حذف کند؛ مرتباً پشتیبان بگیر.
- ذخیره CVV2 ریسک امنیتی دارد. CVV2 فقط در داده رمزگذاری‌شده محلی نگهداری می‌شود و برای نمایش دوباره رمز اصلی لازم است. فقط روی گوشی شخصی و قفل‌شده استفاده کن. رمز اول و رمز دوم بانکی را ذخیره نکن.
- رمزگذاری مرورگر به HTTPS نیاز دارد؛ GitHub Pages این مورد را فراهم می‌کند.
- این برنامه برای استفاده شخصی طراحی شده و جایگزین کیف پول بانکی یا ابزار امنیتی تخصصی نیست.
